# Sitebin Implementation Plan

> **For agentic workers:** Executed inline via superpowers:executing-plans (autonomous goal session; executor has the design doc + this plan in context). Steps use checkbox (`- [ ]`) syntax for tracking. TDD per task; commit per task.

**Goal:** Ship the complete Sitebin product per `docs/superpowers/specs/2026-07-13-sitebin-design.md`: Go backend + Caddy, all-in-one Docker image, tested end-to-end, with a polished modern UI, ready to run at `sitebin.ittrail.cloud`.

**Architecture:** Single Go binary (API, edit/landing UI, WebDAV, authz/tls-check/health, viewer-wrapper generation, cleanup, Caddy supervision) + Caddy 2 (TLS, routing, static serving) over a shared `/data` volume. Filesystem is the database (symlink indexes).

**Tech Stack:** Go 1.24 (stdlib http, x/net/webdav, x/crypto/argon2), Caddy 2 + xcaddy DNS modules, vanilla HTML/CSS/JS embedded via go:embed, vendored pdf.js/markdown-it/DOMPurify/docx-preview/JSZip/highlight.js, Alpine-based multi-stage Dockerfile.

## Global Constraints

- Module path: `github.com/ittrail/sitebin`. Go 1.24. CGO disabled.
- All state under `SITEBIN_DATA_DIR` (default `/data`); no DB.
- IDs: 26-char lowercase base32 (a–z2–7); edit password 22-char base62.
- Argon2id t=1 m=64MiB p=4; plaintext secrets never persisted.
- Reserved upload names: `_sitebin`, `_raw`, `meta.json`; reject `..`, `\`, absolute paths, control chars, uploaded symlinks.
- User content served ONLY on view subdomains / custom domains; UI+API+WebDAV only on base domain; internal endpoints only on internal listener `:9000`.
- Defaults: `SITEBIN_MAX_SITE_BYTES=104857600` (100 MiB), `SITEBIN_MAX_FILES=1000`, create limit 30/h/IP burst 10, password-failure limit 10 per 5 min per (IP,target).
- Windows dev: index links fall back to directory junctions (tests must pass on Windows AND Linux).
- Every commit message ends with the Claude co-author trailer.

### Task 2: auth package

**Files:** `internal/auth/argon2.go`, `internal/auth/token.go`, `internal/auth/ratelimit.go`, `internal/auth/cache.go` (+ tests)

**Produces:**
- `auth.HashPassword(pw string) string` (PHC string `$argon2id$v=19$m=65536,t=1,p=4$...`), `auth.VerifyPassword(hash, pw string) bool` (constant-time, tolerant of bad hash strings).
- `auth.LoadOrCreateSecret(path string) ([]byte, error)` (32 random bytes, 0600).
- `auth.TokenSigner{secret}`: `Sign(siteID string, now time.Time, ttl time.Duration) string`; `Verify(token, siteID string, now time.Time) bool` (HMAC-SHA256 over siteID|exp, base64url, constant-time).
- `auth.VerifyCache`: `Check(key string) bool` / `Put(key string)` with TTL (5 min) — key = editID + ":" + sha256hex(pw).
- `auth.Limiter`: token bucket `Allow(key string) bool` with rate/burst + janitor; `auth.NewLimiter(perHour float64, burst int)`. Failure tracker = Limiter keyed `ip|target` at RateAuthPer5Min.

**Tests:** hash/verify round-trip; wrong pw false; malformed hash false; token round-trip, expiry, wrong site, tampered sig; cache TTL; limiter allows burst then denies, refills over time (fake clock via injectable `now func()`).

- [ ] Tests → implement → pass → commit `feat: auth primitives (argon2id, tokens, rate limiting)`

### Task 3: store package (filesystem database)

**Files:** `internal/store/store.go`, `meta.go`, `files.go`, `links.go`, `links_windows.go`, `zip.go` (+ tests with fixture zips built in-test)

**Produces:**
- `store.Meta` — exact PRD §8 JSON schema (`id, edit_id, edit_password_hash, mode, view_password_protected, view_password_hash, webdav_enabled, custom_domains, entry_file, expires_at *time.Time, created_at, updated_at`).
- `store.New(dataDir string, maxSiteBytes int64, maxFiles int) *Store` — creates `sites/`, `edit-index/`, `domain-index/`.
- `Create() (*Site, string /*editPassword*/, error)`; `Site{ViewID, EditID string, Meta Meta}`, `Site.Dir()`, `Site.FilesDir()`.
- `ByEditID / ByViewID / ByDomain (string) (*Site, error)` (ErrNotFound); per-site mutex map; `Update(site *Site, mutate func(*Meta) error) error` (atomic write meta.json.tmp→rename, bumps updated_at).
- `SaveFile(site, relPath string, r io.Reader) error` — sanitizes path (`CleanRelPath(p string) (string, error)`), enforces MaxFiles + MaxSiteBytes (counts existing usage), creates parent dirs, O_CREATE|O_TRUNC only.
- `ExtractZip(site, r io.ReaderAt, size int64) error` — same limits, rejects symlink entries (mode&os.ModeSymlink), rejects traversal.
- `DeleteFile(site, relPath)`, `ListFiles(site) ([]FileInfo{Path,Size})`, `ClearFiles(site)` (wipe files/ except keep dir).
- `AddDomain(site, domain string) error` (validate RFC hostname regex, lowercase, reject base domain + subdomains of base, reject already-taken → ErrDomainTaken), `RemoveDomain`, `Delete(site)` (folder + edit-index + domain links).
- `links.go`: `makeLink(target, link string) error` (os.Symlink; windows file fallback: junction via `cmd /c mklink /J`), `resolveLink(link string) (viewID string, err)`.

**Tests:** create → dirs + meta + indexes exist, edit pw hash verifies; lookups by all three keys; traversal (`../x`, `a/../../x`, `C:\x`, `/etc/passwd`, `_raw/x`, `_sitebin/x`, `meta.json`) rejected; MaxFiles & MaxSiteBytes enforced incl. zip; zip with symlink entry rejected; nested zip paths extract; domain validation matrix (valid, uppercase→lower, `bad_domain!`, base domain, `x.<base>` rejected, duplicate rejected); delete removes links; Update concurrent-safe (t.Parallel hammer).

- [ ] Tests → implement → pass (Windows local) → commit `feat: filesystem store with indexes, uploads, zip extraction`

### Task 5: caddygen

**Files:** `internal/caddygen/caddygen.go` (+test with golden strings)

**Produces:** `caddygen.Generate(cfg config.Config) string` emitting:
- global block: `admin off`, `storage file_system /data/caddy`, `email`, `on_demand_tls ask http://<backendhost>:9000/internal/tls-check`, `auto_https off` when HTTPOnly.
- base-domain site: `reverse_proxy <backendhost>:8080`.
- wildcard site `*.<base>`: tls dns provider/token (or TLSSnippet; omitted when HTTPOnly), `@backend path /_sitebin/*`→proxy, else `forward_auth <backendhost>:8080 { uri /internal/authz... }` — **NOTE:** forward_auth must target the *internal* listener via proxy-safe route: use `forward_auth <backendhost>:9000 { uri /internal/authz }`, `root * <data>/sites/{labels.N}/files`, `file_server browse`, custom 404 handling.
- catch-all custom-domain site (`https://` / `http://:80` in HTTPOnly) with `tls { on_demand }`, same shape, root `<data>/domain-index/{host}/files`.
- label index N computed from base-domain label count.

**Tests:** golden output for (a) cloudflare HTTPS config with base `sitebin.ittrail.cloud` → contains `{labels.3}`, on_demand_tls ask, dns cloudflare; (b) HTTP-only localtest.me config → `auto_https off`, `http://` hosts, no tls blocks.

### Task 6: httpapi — public API, internal endpoints, WebDAV

**Files:** `internal/httpapi/api.go`, `sites.go`, `internalh.go`, `webdav.go`, `gate.go`, `server.go` (+ `httpapi_test.go` covering all endpoints via httptest)

**Consumes:** store, auth, viewer, config as defined above.

**Produces:** `httpapi.New(cfg, st *store.Store, signer auth.TokenSigner, ...) *API` with `Public() http.Handler` and `Internal() http.Handler`.

Public routes (`:8080`): `POST /api/sites` (multipart: files/zip/mode/view_password/expires_at/webdav_enabled/custom domains — create limited by IP limiter; honors ReadOnly); `GET|PUT|DELETE /api/sites/{edit}`; `POST /api/sites/{edit}/files`; `DELETE /api/sites/{edit}/files/{path...}`; `POST /api/sites/{edit}/domains` + `DELETE .../domains/{domain}`; `ANY /dav/{edit}/...` (Basic, webdav.Handler rooted at files/, gated by global+per-site flags, verify-cache); `GET /e/{edit}` (edit UI shell); `GET /` (landing); `GET /_sitebin/assets/...` (embedded, cache headers); `POST /_sitebin/unlock` (form pw → verify view hash by Host → Set-Cookie signed token → 303 to `redirect` form value, sanitized to same-origin path); JSON errors `{"error": "..."}`; security headers middleware.

Internal routes (`:9000`): `GET /internal/authz` (Host header → site: 200 / 401+gate HTML / 410 / 404; skips gate when `view_password_protected=false`; validates `sitebin_v` cookie); `GET /internal/tls-check?domain=` (200/404); `GET /internal/health` (200 JSON).

Auth middleware for edit routes: `X-Edit-Password` (also accepts Basic pw for curl convenience), verify-cache + failure limiter → 401/429.

**Tests (httptest matrix):** create returns view_url/edit_url/edit_password once and hash!=plaintext; GET meta w/ wrong pw 401, right pw 200 (never contains hash); PUT mode viewer→wrapper exists, back→restored; PUT expiry beyond MaxExpiryDays clamped/400; file upload + delete + traversal 400; domains add/remove (+tls-check flips 404→200→404); view-password flow: authz 401 (body contains form) → unlock sets cookie → authz 200; expired site → 410; unknown host → 404; WebDAV: PROPFIND/PUT/GET/DELETE with Basic pw, disabled → 404, wrong pw → 401, global off → 404; rate limit: 11th bad pw → 429; create flood → 429; ReadOnly → 503 on create; health 200.

- [ ] Tests → implement → pass → commit `feat: HTTP API, authz gate, WebDAV`
