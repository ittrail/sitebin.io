# Git Repository per Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every site can hold one bare Git repository, reached over smart HTTP at
`/git/<edit-id>.git`, counted against the site's byte quota, browsable read-only in a
new "Git" tab on the edit page, paid-only on the hosted instance through a stamped
`git` tier flag.

**Architecture:**
- A new core package `internal/gitrepo` wraps the system `git` binary: smart HTTP, read
  queries and gc, with a fixed server-owned environment.
- `internal/httpapi` owns the gate. Basic auth is turned into the same standing
  `withEditAuth` uses, plus OAuth for the Git route only. It also owns the Git
  endpoint, the REST read routes and provenance.
- `internal/store` owns the repository's place (`sites/<id>/git/`), the combined byte
  count, the `quota_git` stamp and repository deletion.
- The tier flag is stamped like `webdav`, and the sweep reconciles and collects.

**Tech Stack:** Go 1.25 (stdlib `net/http`, `os/exec`), system `git` (Alpine 3.22
package, protocol v2), vanilla JS edit page, vendored highlight.js, PowerShell e2e.

**Spec:** `docs/superpowers/specs/2026-11-03-site-git-design.md` — read it first;
this plan argues from it.

## Global Constraints

- **Run both suites, every task:** `go vet ./...`, `go test ./...` and
  `go test -tags ee ./...`.
- **The community build stays whole:** every seam addition is inert with no provider,
  and has a community-path test.
- **The filesystem is the database:** new `Meta` fields are `omitempty`, and a missing
  field means its zero value.
- **Git binary:** found with `exec.LookPath("git")` at startup.
  - Tests that need it call `gitrepo.NeedGit(t)`, which skips when it is absent.
  - Both Dockerfile stages `apk add --no-cache git`, so the image build runs those tests.
- **Every git process runs with this fixed environment.** It is built from an empty
  slice, never from `os.Environ()`, and only `PATH` is copied in:
  - `GIT_CONFIG_NOSYSTEM=1` and `GIT_ATTR_NOSYSTEM=1`;
  - `GIT_CONFIG_GLOBAL=<state>/empty.gitconfig`, an empty file the runner creates. On
    Windows test hosts this must never be `/dev/null`;
  - `HOME=<state>/home` and `GIT_TERMINAL_PROMPT=0`;
  - `GIT_PROTOCOL` only when the client's `Git-Protocol` header is exactly
    `version=2`.

  `<state>` is `<data>/gitstate/`.
- **Every git process gets these `-c` settings:**
  - `core.hooksPath=<state>/empty-hooks` and `core.logAllRefUpdates=false`;
  - `receive.fsckObjects=true` and `transfer.fsckObjects=true`;
  - `receive.autogc=false` and `uploadpack.allowAnySHA1InWant=false`;
  - `pack.threads=1`, `pack.windowMemory=64m` and `core.packedGitLimit=128m`;
  - and, for a push, `receive.maxInputSize=<allowance>`.
- **Environment variables and their defaults:**
  - `SITEBIN_GIT_ENABLED` = `true`;
  - `SITEBIN_GIT_MAX_PUSH_BYTES` = `536870912` (512 MiB);
  - `SITEBIN_GIT_MAX_PROCESSES` = `4`;
  - `SITEBIN_GIT_OAUTH_CLIENT_ID` = `""`.
- **Limits:**
  - `LogPage = 30` commits;
  - `MaxChangedFiles = 300`;
  - `MaxTextBytes = 512 << 10`;
  - `MaxTreeEntries = 5000`;
  - `ReadTimeout = 15 * time.Second` per read command;
  - gc prunes with `--prune=1.day.ago`;
  - pushes are bounded by the existing server `ReadTimeout` (10 min).
- **Repository path:** `filepath.Join(site.dir, "git")`, outside `files/`.
- **OAuth tokens act on `/mcp` and on `/git/` only.** The REST API keeps refusing them.
- **No MCP catalog change, and no new field in any MCP output.**
- **UI copy, exact:**
  - "This repository belongs to this site. Deleting the site deletes the repository."
  - with an expiry date: "The site expires on <date>; the repository goes with it."
- **Commits:**
  - lowercase conventional prefix, with a subject about the behaviour;
  - end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - `e2e/*.ps1` stays pure ASCII.
- **Owner-only today means every credential the gate accepts.** Ownership adds admins
  later (spec, "Before planning"). Do not build admin logic.

## Review Focus

1. **An oversize push leaves no residue.** After Git refuses a pack over
   `receive.maxInputSize`, the repository's bytes are unchanged and no
   `objects/incoming-*` or `tmp_pack_*` remains (Task 2 test).
2. **An empty repository**, a fresh `init` with an unborn `main`, answers every read
   route with empty lists and `exists: true`, never a 500 (Task 3 test).
3. **Odd names and refs** list, resolve and download correctly:
   - a file named `a"b\nc.txt` and `ümlaut.md`;
   - a branch `feature/x`;
   - a tag and a branch both named `v1` (the branch wins, `refs/tags/v1` reaches the
     tag).

   Task 3 test.
4. **Deleting or locking a site while a push streams:** the push is cancelled, its
   process has exited before the folder is removed, and no `sites/<id>` folder
   survives the delete (Tasks 6 and 9 tests).
5. **A folder with more than 5000 entries** lists 5000 with `truncated: true`; a binary
   file is never returned as text (Task 3 test).

### Task 2: Smart HTTP in `gitrepo`

**Files:**
- Create: `internal/gitrepo/smarthttp.go`, `internal/gitrepo/pktline.go`
- Create: `internal/gitrepo/smarthttp_test.go`

**Interfaces:**
- Consumes: Task 1's `Runner.command` and `acquire`.
- Produces:
  - `type Service string`, with constants `UploadPack = "git-upload-pack"` and
    `ReceivePack = "git-receive-pack"`.
  - `func ParseService(s string) (Service, bool)`
  - `func ProtocolFromHeader(h string) string`: returns `"version=2"` or `""`.
  - `func (r *Runner) AdvertiseRefs(ctx context.Context, dir string, svc Service, protocol string, w http.ResponseWriter) error`
    - sets `Content-Type: application/x-<svc>-advertisement` and
      `Cache-Control: no-cache`;
    - writes `pkt("# service=<svc>\n")` and a flush **only when `protocol` is not
      v2**, as `git http-backend` does;
    - then the output of `<svc> --stateless-rpc --advertise-refs .`.
  - `type RPCOptions struct { Protocol string; Gzip bool; MaxInputSize int64 }`
  - `type RefUpdate struct { Ref, Old, New string }` (40 zeros = created/deleted)
  - `type RPCResult struct { Updates []RefUpdate; BytesIn int64 }`
  - `func (r *Runner) ServeRPC(ctx context.Context, dir string, svc Service, body io.Reader, w http.ResponseWriter, o RPCOptions) (RPCResult, error)`
    - decodes gzip when `o.Gzip`;
    - for receive-pack, reads the command pkt-lines up to the first flush into
      `Updates`, then streams that prefix plus the rest into git's stdin;
    - counts `BytesIn`;
    - `Content-Type: application/x-<svc>-result`;
    - returns an error when git exits non-zero.
  - `func WriteRefusal(w http.ResponseWriter, svc Service, msg string)`:
    `200`, the advertisement content type, and
    `pkt("# service=<svc>\n") + "0000" + pkt("ERR " + msg + "\n")`. The spike proved
    this prints `fatal: remote error: <msg>` for v0 and v2.

  - `func (r *Runner) Blob(ctx, dir, sha, path string) (Blob, error)`: text up to

  - `func (r *Runner) WriteBlob(ctx, dir, sha, path string, w io.Writer) error`
