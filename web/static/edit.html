Containers 


    

      The project runs what sitebin-container-compose.yaml in the site's root declares, and
      every change to that file restarts it — however you save it. Each root folder is a
      volume: upload your app into the folder a service mounts. * maps the site's own address;
      any other domain in the file is a custom domain and needs the DNS record shown here.

Access

    

      
      

        
        
        
      

      
    

    

      
      

        Mount 

        Any username · password = your edit password.
        

          On plain HTTP: Windows Explorer and macOS Finder refuse to send
          the password over an unencrypted connection, so mounting fails with a 401. Use an
          HTTPS instance, or a client that allows it — rclone, WinSCP, Cyberduck,
          or curl. (Windows: set BasicAuthLevel to 2 and restart the
          WebClient service.)
        

      

    

    

      
      

        Connect 

        Username = your site's edit UUID · password = your edit password.
        

          Heads-up: plain FTP sends your password unencrypted — use it only on a
          trusted network (or an FTPS-configured instance). Clients: FileZilla, WinSCP, curl, rclone.
        

      

    

    

      
      

        
        
        
      

      
    

  


  

    
Custom domains

    

    

      
      
    

    

      A domain is attached once its DNS proves it belongs to this site: a TXT record with the token shown
      after you add it, or a CNAME at the domain pointing at this site's own address. Route it with
      A → your server IP or that CNAME ( also works for routing,
      but only the site's own address counts as proof). The certificate is issued automatically on the first visit.
    

  


  

    
Forms 

    
This site's plan includes no forms.

    

    

      

        
        
      

      

        
        
        
      

      

        
        
      

    

    

      A form mails what visitors submit to its recipient, who confirms once by email before the form goes live.
      Paste its snippet into any page of this site: it is plain HTML and needs no script unless the captcha is on.
      Every mail lays out the fields, carries the attachments, and includes a submission.json for machines.
