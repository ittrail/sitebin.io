Access

Mount
Any username · password = your edit password.
On plain HTTP: Windows Explorer and macOS Finder refuse to send the password over an unencrypted connection, so mounting fails with a 401. Use an HTTPS instance, or a client that allows it — rclone, WinSCP, Cyberduck, or curl. (Windows: set BasicAuthLevel to 2 and restart the WebClient service.)
